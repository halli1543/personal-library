# Personal Library

A downloadable app to keep track of your book library fully offline — no account required.

## Features
- Add, edit, and delete books
- Search by title, author, or notes
- Filter by genre and reading status
- Export library to CSV and JSON
- Fully offline, no internet required
- Linux-first (Ubuntu/Debian), Windows planned

## Tech Stack
- **Language:** Python 3
- **Database:** SQLite
- **GUI:** tkinter (with ttkbootstrap for theming)
- **Packaging:** .deb, Flatpak

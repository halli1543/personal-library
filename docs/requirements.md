Purpose

the putpose of this app is so people can keep track of library and reading.

Primary users

people who want to have a digital archive of their library

problem

An offline digital library application that allows people to keep track of their books without needing to create an account with Libib or other services.


Functional requirements

FR-01: the system shall return every book whose title, author, or notes contains the complete search query, ignoring letter case. results shall update when the user submits the qurey.
FR-02: users should be able to filter books by genre, reading status.
FR-O3: users should be able to export to CSV and JSON
FR-O4: users should be albe to add, edit, and delete books
